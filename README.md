# KiwiDesk for Claude Code

The Claude Code plugin marketplace for
[KiwiDesk](https://kiwidesk.kiwicanopy.com), the tiling window manager
for macOS. The plugin connects Claude Code to KiwiDesk's own MCP server
(`kiwidesk mcp`), so you can set up and control KiwiDesk by asking
Claude.

**Coming with KiwiDesk 3.0.** The plugin lands here when 3.0 is
released. Its source lives in the main repository,
[KiwiCanopy/KiwiDesk](https://github.com/KiwiCanopy/KiwiDesk), under
`plugins/`, and this repository is synced from it at each release —
please open issues and pull requests there.
